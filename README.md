# 🍗 CHicks (شِيكس) - المنيو الإلكتروني الرسمي

المنيو الإلكتروني التفاعلي بـ QR Code لمطعم **CHicks (شِيكس) • The King of Crunch** - طامية، الفيوم.

---

## 🌟 المميزات الرئيسية
- 📱 **واجهة عصرية متجاوبة 100%:** مصممة خصيصاً للموبايل وتعمل بسلاسة على كافة الشاشات وأجهزة التابلت والكمبيوتر.
- 🎨 **هوية بصرية موحدة:** ثيم Dark Mode فاخر مستوحى من ألوان وهوية شِيكس (الأسود الفحمي، الأحمر الملكي، واللمسات الذهبية).
- 🧾 **حاسبة أسعار وفاتورة فورية:** إمكانية إضافة الوجبات وتحديد الكميات وحساب الإجمالي التقريبي لحظياً مع إمكانية نسخ الطلب أو إرساله بضغطة زر.
- 🍗 **محدد أحجام المشويات:** اختيار الحجم (كامل • نص • ربع) للأصناف المشوية مع تحديث فوري للسعر.
- 💬 **طلب مباشر عبر واتساب:** إرسال تفاصيل الطلب بالكامل منسقة للواتساب الخاص بالمطعم.
- 📞 **أزرار اتصال سريع:** أرقام الدليفري (فودافون + اتصالات) بضغطة زر واحدة.
- 🔳 **مولد كود QR تفاعلي:** نافذة مخصصة لإنشاء وتحميل وطباعة كود الـ QR لوضعه على طاولات الصالة وعلب الدليفري.
- 🔍 **بحث وتصفية ذكية:** فلترة سريعة بالأقسام (بروست، مشويات، طواجن، كريب، سلطات، مشروبات) أو بالوسوم (الأكثر طلباً، سبايسي، عائلي).
